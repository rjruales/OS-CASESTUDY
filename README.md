# OS-CASESTUDY

How to run the program:
1. Download 3 files (index.html, app.js and style.css).
2. Open the index.html using your preferred browser.
3. Select an algorithm from the left sidebar (FCFS, SJF, SRT, Round Robin, Priority, or Priority + RR).
4. Configure processes in the Process Configuration panel:
    - Edit the Process ID, Arrival Time, and Burst Time for each row.
    - For Priority algorithms, a Priority column will appear.
    - For Round Robin / Priority + RR, set the Time Quantum field.
    - Use + Add Process to add more rows (up to 10 colors supported).
5. Click Run Simulation to generate results.
6. View the Gantt Chart, Process Summary table, and stat cards.
7. Use Reset to clear all results and start fresh.
